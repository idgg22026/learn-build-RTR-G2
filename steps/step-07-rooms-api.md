# Step 7 — First REST API: Rooms CRUD

## Goal
`GET/POST/PUT/PATCH/DELETE /api/rooms` work with validation, search, filters and pagination.

## You will learn
The pattern used by **every** feature in RTR Room:

```
Route ─► FormRequest (validate) ─► Controller (thin) ─► Model / Service ─► Resource (JSON shape)
```

## Files
| File | Action |
|---|---|
| `app/Http/Requests/StoreRoomRequest.php`, `UpdateRoomRequest.php` | Generated by `make:request`, then edited |
| `app/Http/Resources/RoomResource.php` | Generated by `make:resource`, then edited |
| `app/Http/Controllers/RoomController.php` | Generated by `make:controller`, then edited |
| `routes/api.php` | Edited manually |

## Do it
```bash
docker compose exec laravel php artisan make:request StoreRoomRequest

```

**`StoreRoomRequest.php`**
```php
public function authorize(): bool
{
    return true; // the route middleware already checks the role
}

public function rules(): array
{
    return [
        'room_number' => ['required', 'string', 'max:20',
            Rule::unique('rooms', 'room_number')->whereNull('deleted_at')],
        'floor'       => ['nullable', 'integer', 'min:0', 'max:255'],
        'type'        => ['nullable', 'string', 'max:50'],
        'rent_price'  => ['required', 'numeric', 'min:0'],
        'status'      => ['sometimes', Rule::in(Room::STATUSES)],
        'description' => ['nullable', 'string', 'max:1000'],
    ];
}
```
`UpdateRoomRequest` is the same, but the unique rule ignores the current room:
`Rule::unique('rooms', 'room_number')->ignore($this->route('room'))->whereNull('deleted_at')`.

**`RoomResource.php`** — you decide exactly what Vue receives:
```php
public function toArray(Request $request): array
{
    return [
        'id'          => $this->id,
        'room_number' => $this->room_number,
        'floor'       => $this->floor,
        'type'        => $this->type,
        'rent_price'  => (float) $this->rent_price,
        'status'      => $this->status,
        'description' => $this->description,
        'created_at'  => $this->created_at?->toDateTimeString(),
    ];
}
```

**`RoomController.php`**
```php
// GET /api/rooms?search=A1&status=available&per_page=10
public function index(Request $request)
{
    $rooms = Room::query()
        ->when($request->search, function ($query, $search) {
            $query->where(function ($q) use ($search) {
                $q->where('room_number', 'like', "%{$search}%")
                  ->orWhere('type', 'like', "%{$search}%");
            });
        })
        ->when($request->status, fn ($query, $status) => $query->where('status', $status))
        ->orderBy('room_number')
        ->paginate($request->integer('per_page', 10));

    return RoomResource::collection($rooms);   // adds "meta" + "links" for pagination
}

public function store(StoreRoomRequest $request)
{
    $room = Room::create($request->validated());

    return (new RoomResource($room))
        ->additional(['message' => 'Room created successfully.'])
        ->response()->setStatusCode(201);
}

public function show(Room $room)            // route-model binding
{
    return new RoomResource($room);
}

public function update(UpdateRoomRequest $request, Room $room)
{
    $room->update($request->validated());

    return (new RoomResource($room))->additional(['message' => 'Room updated successfully.']);
}

public function updateStatus(Request $request, Room $room)
{
    $data = $request->validate(['status' => ['required', Rule::in(Room::STATUSES)]]);
    $room->update($data);

    return (new RoomResource($room))->additional(['message' => 'Room status updated.']);
}

public function destroy(Room $room)
{
    if ($room->status === 'occupied') {
        return response()->json(['message' => 'Cannot delete an occupied room.'], 422);
    }
    $room->delete();

    return response()->json(['message' => 'Room deleted successfully.']);
}
```

**`routes/api.php`** (no login yet — step 8 wraps these in role groups)
```php
Route::get('rooms', [RoomController::class, 'index']);
Route::get('rooms/{room}', [RoomController::class, 'show']);
Route::post('rooms', [RoomController::class, 'store']);
Route::match(['put', 'patch'], 'rooms/{room}', [RoomController::class, 'update']);
Route::patch('rooms/{room}/status', [RoomController::class, 'updateStatus']);
Route::delete('rooms/{room}', [RoomController::class, 'destroy']);
```

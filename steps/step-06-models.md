# Step 6 — Eloquent models

## Goal
`Room` and `Tenant` models with **constants**, **casts**, **fillable** fields and **relations** that the rest of the
app (validation, Vue dropdowns, services) reuses.

## You will learn
- Keeping allowed values in one place (`Room::STATUSES`) and reusing them in validation and resources
- `$casts` for money/dates, `$attributes` for defaults, `SoftDeletes`
- Relations: `hasMany`, `belongsTo`, a filtered `hasOne` (`activeTenant`)

## Files
| File | Action |
|---|---|
| `app/Models/Room.php` | Generated by `make:model`, then edited |
| `app/Models/Tenant.php` | Generated by `make:model`, then edited |

## Do it
```bash
docker compose exec laravel php artisan make:model Room
docker compose exec laravel php artisan make:model Tenant
```

**`app/Models/Room.php`**
```php
class Room extends Model
{
    use SoftDeletes;

    // owner_use: the owner lives in or uses the room; no tenant, no invoices
    public const STATUSES = ['available', 'occupied', 'maintenance', 'owner_use'];

    protected $fillable = ['room_number', 'floor', 'type', 'rent_price', 'status', 'description'];

    protected $attributes = ['status' => 'available'];

    protected $casts = [
        'floor' => 'integer',
        'rent_price' => 'decimal:2',
    ];

    // All tenants who have ever rented this room
    public function tenants(): HasMany
    {
        return $this->hasMany(Tenant::class);
    }

    // The tenant currently living in this room
    public function activeTenant(): HasOne
    {
        return $this->hasOne(Tenant::class)->where('status', 'active');
    }
}
```

**`app/Models/Tenant.php`**
```php
class Tenant extends Model
{
    use SoftDeletes;

    public const STATUSES = ['active', 'moved_out'];
    public const GENDERS = ['male', 'female', 'other'];

    protected $fillable = [
        'full_name', 'gender', 'phone', 'email', 'id_card_number', 'address',
        'emergency_contact_name', 'emergency_contact_phone',
        'room_id', 'move_in_date', 'move_out_date', 'status', 'notes',
    ];

    protected $attributes = ['status' => 'active'];

    protected $casts = [
        'move_in_date' => 'date',
        'move_out_date' => 'date',
    ];

    // withTrashed: an old invoice still shows the room even if the room was deleted later
    public function room(): BelongsTo
    {
        return $this->belongsTo(Room::class)->withTrashed();
    }
}
```

> **Main point:** as features grow, the model gains fields (`photo_path`, `start_electric_meter`,
> `handover_items` as `array` cast…) and relations (`documents()`, `occupants()`, `meterReadings()`).
> Add each one **together with its migration**.

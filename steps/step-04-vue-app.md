# Step 4 — Create the Vue SPA

## Goal
http://localhost:5173 shows a Vue 3 app styled with AdminLTE, with Pinia and Vue Router ready.

## You will learn
- `npm create vue` options (Router + Pinia, JavaScript)
- Loading a classic CSS framework (AdminLTE/Bootstrap 4) in a Vite app
- The `@` alias and `VITE_` environment variables

## Files
| File | Action |
|---|---|
| `vuejs-app/` | Generated by command |
| `vuejs-app/.env`, `.env.example` | Created manually |
| `vuejs-app/src/main.js` | Generated, then edited |
| `vuejs-app/src/assets/rtr-theme.css` | Created manually (filled in step 10) |

## Do it
```bash
docker run --rm -it -v "$PWD":/app -w /app node:22-alpine npm create vue@latest vuejs-app
# choose: Router = Yes, Pinia = Yes, everything else = No

docker compose run --rm vuejs npm install \
  admin-lte@^3.2 bootstrap@^4.6 jquery@^3.7 @fortawesome/fontawesome-free@^5.15 \
  axios pinia vue-router sweetalert2 qrcode
```

**`vuejs-app/.env`** (and the same in `.env.example`)
```
VITE_API_URL=http://localhost:8000/api
```

**`vuejs-app/src/main.js`**
```js
// AdminLTE + Bootstrap + Icons (CSS)
import '@fortawesome/fontawesome-free/css/all.min.css'
import 'admin-lte/dist/css/adminlte.min.css'
import './assets/rtr-theme.css'

// AdminLTE + Bootstrap (JS)
import 'bootstrap/dist/js/bootstrap.bundle.min.js'
import 'admin-lte/dist/js/adminlte.min.js'

import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.mount('#app')
```

**`src/App.vue`** — keep it tiny; layouts come from the router:
```vue
<template>
  <router-view />
</template>
```

Create an empty `src/assets/rtr-theme.css`, then start the dev server:
```bash
docker compose up -d vuejs
```

## Check
http://localhost:5173 loads, and DevTools → Network shows `adminlte.min.css` loaded.

## Practice
Paste an AdminLTE "small box" (`<div class="small-box bg-info">…`) into `App.vue` and see the styling work.
Then remove it.

git add . && git commit -m "Step 4: Vue 3 SPA with AdminLTE, Pinia and Router"

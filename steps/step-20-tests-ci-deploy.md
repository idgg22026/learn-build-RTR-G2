# Step 20 — Tests, demo data, CI and deployment

## Goal
`php artisan test` proves the rules, `php artisan rtr:demo` fills a realistic demo in one command, GitHub Actions
runs tests + a build on every push, and the database is backed up every day.

## You will learn
- Feature tests that call the **real API** (`postJson`, `assertJsonPath`) with `RefreshDatabase` and fake storage
- A demo command that also goes **through the API**, so the demo obeys the same rules as real use
- CI with SQLite in memory: no secrets needed
- A safe backup script that checks its own output

## Do it

**A feature test** (`php artisan make:test RoomAccessTest`)
```php
class RoomAccessTest extends TestCase
{
    use RefreshDatabase;

    public function test_viewer_can_read_but_not_create_rooms(): void
    {
        Sanctum::actingAs(User::factory()->create(['role' => 'viewer']));

        $this->getJson('/api/rooms')->assertOk();
        $this->postJson('/api/rooms', ['room_number' => 'A1', 'rent_price' => 100])->assertForbidden();
    }

    public function test_staff_cannot_delete_but_owner_can(): void
    {
        $room = Room::create(['room_number' => 'A1', 'rent_price' => 100]);

        Sanctum::actingAs(User::factory()->create(['role' => 'staff']));
        $this->deleteJson("/api/rooms/{$room->id}")->assertForbidden();

        Sanctum::actingAs(User::factory()->create(['role' => 'owner']));
        $this->deleteJson("/api/rooms/{$room->id}")->assertOk();
        $this->assertSoftDeleted($room);
    }
}
```
Pattern used by the project's tests (`PaymentProofTest`, `RoomItemTest`, …): `Storage::fake('local')`, build data
with the API (`postJson('/api/meter-readings', …)`, `postJson('/api/invoices/generate', …)`), then assert the
JSON **and** the database.

**Demo data command** (`php artisan make:command DemoData`)
```php
protected $signature = 'rtr:demo {--fresh : Drop all tables and migrate again before filling}';

public function handle(): int
{
    if (app()->isProduction()) { $this->error('Refused: APP_ENV is production.'); return 1; }
    if ($this->option('fresh')) $this->call('migrate:fresh', ['--force' => true]);
    if (User::exists() || Room::exists()) { $this->error('The database is not empty. Use --fresh.'); return 1; }

    // create owner/staff/viewer (password Demo1234), 6 rooms, 5 tenants, 4 months of readings → invoices → payments,
    // a pending KHQR receipt, repairs, a move-out notice, main meters, expenses — each step through the real API
    ...
    return 0;
}
```

**`.github/workflows/ci.yml`**
```yaml
name: CI
on:
  push: { branches: [master, main] }
  pull_request:
permissions: { contents: read }
jobs:
  laravel:
    runs-on: ubuntu-latest
    defaults: { run: { working-directory: laravel-app } }
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with: { php-version: '8.3', extensions: 'mbstring, pdo_sqlite, sqlite3, bcmath, intl, gd, zip', coverage: none }
      - run: composer install --no-interaction --prefer-dist --no-progress
      - run: cp .env.example .env && php artisan key:generate
      - run: php artisan test
      - run: composer audit
        continue-on-error: true
  vue:
    runs-on: ubuntu-latest
    defaults: { run: { working-directory: vuejs-app } }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '22', cache: npm, cache-dependency-path: vuejs-app/package-lock.json }
      - run: npm ci
      - run: npm run build
```

**`scripts/backup.sh`** (daily via cron: `30 2 * * * /path/to/scripts/backup.sh >> ~/rtr-backup.log 2>&1`)
```bash
#!/bin/bash
set -euo pipefail
cd "$(dirname "$0")/.."
DEST="${RTR_BACKUP_DIR:-$HOME/RTRroom-backups}"
STAMP=$(date +%Y%m%d-%H%M)
mkdir -p "$DEST/monthly"

docker compose exec -T mysql sh -c 'exec mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" --single-transaction "$MYSQL_DATABASE"' \
  | gzip > "$DEST/db-$STAMP.sql.gz"
TABLES=$(gzip -dc "$DEST/db-$STAMP.sql.gz" | grep -c "CREATE TABLE" || true)
[ "$TABLES" -lt 10 ] && { echo "FAILED: only $TABLES tables" >&2; exit 1; }   # never trust an empty dump
tar -czf "$DEST/files-$STAMP.tar.gz" -C laravel-app/storage app
[ "$(date +%d)" = "01" ] && cp "$DEST/db-$STAMP.sql.gz" "$DEST/files-$STAMP.tar.gz" "$DEST/monthly/"
find "$DEST" -maxdepth 1 -name '*.gz' -mtime +30 -delete
```

**Production checklist**
- [ ] `APP_ENV=production`, `APP_DEBUG=false`, a new `APP_KEY`
- [ ] `npm run build` → serve `vuejs-app/dist` with Nginx; proxy `/api` and `/sanctum` to PHP-FPM (not `artisan serve`)
- [ ] HTTPS; `SESSION_SECURE_COOKIE=true`; `SESSION_DOMAIN` and `SANCTUM_STATEFUL_DOMAINS` = your real domain
- [ ] `php artisan config:cache route:cache view:cache`
- [ ] Create the owner with `php artisan rtr:user`, never with demo data
- [ ] Backups run and you have **tested a restore**

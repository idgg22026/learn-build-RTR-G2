# Step 3 — Create the Laravel API app

## Goal
`http://localhost:8000/up` answers, Laravel talks to MySQL, and Sanctum is installed for cookie login.

## You will learn
- Creating a Laravel 13 project inside Docker
- `.env` for the database, session and CORS
- `bootstrap/app.php`: API routes, middleware aliases, always-JSON errors

## Files
| File | Action |
|---|---|
| `laravel-app/` | Generated by command |
| `laravel-app/.env` | Generated, then edited manually |
| `laravel-app/routes/api.php`, `config/sanctum.php`, `config/cors.php` | Generated by `install:api`, then edited |
| `laravel-app/bootstrap/app.php` | Modified manually |

## Do it
```bash
# 1. Create the project with the Composer image (no PHP needed on your computer)
docker run --rm -v "$PWD":/app -w /app composer:2 create-project laravel/laravel laravel-app

# 2. API routes + Sanctum
docker compose run --rm laravel php artisan install:api
```

**`laravel-app/.env`** — change these lines:
```
APP_NAME="RTR Room"
DB_CONNECTION=mysql
DB_HOST=mysql          # the compose service name, not 127.0.0.1
DB_PORT=3306
DB_DATABASE=rtr_room
DB_USERNAME=rtr_user
DB_PASSWORD=change-me  # same as MYSQL_PASSWORD

SESSION_DRIVER=database
SESSION_DOMAIN=localhost
FRONTEND_URL=http://localhost:5173
SANCTUM_STATEFUL_DOMAINS=localhost:5173
```

**`config/cors.php`** — the Vue app is on another port, so it must be allowed **with credentials**:
```php
'paths' => ['api/*', 'sanctum/csrf-cookie'],
'allowed_origins' => array_filter(explode(',', env('FRONTEND_URL', 'http://localhost:5173'))),
'allowed_headers' => ['*'],
'allowed_methods' => ['*'],
'supports_credentials' => true,
```

**`bootstrap/app.php`**
```php
return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware): void {
        // The Vue app logs in with a session cookie (Sanctum SPA authentication)
        $middleware->statefulApi();
        // aliases are added in step 8 (role) and step 19 (log.activity)
    })
    ->withExceptions(function (Exceptions $exceptions): void {
        // Errors from /api/* are always JSON, never an HTML page
        $exceptions->shouldRenderJsonWhen(
            fn (Request $request) => $request->is('api/*') || $request->expectsJson(),
        );
    })->create();
```

```bash
docker compose up -d laravel
docker compose exec laravel php artisan key:generate
docker compose exec laravel php artisan migrate
```

## Check
- http://localhost:8000/up shows a green "Application up".
- phpMyAdmin → `rtr_room` has `users`, `sessions`, `cache`, `jobs`, `personal_access_tokens`.

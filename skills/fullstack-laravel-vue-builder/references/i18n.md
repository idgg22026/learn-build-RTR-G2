# i18n without a library

```js
// src/i18n/index.js
import { computed, ref } from 'vue'
import en from './en'; import km from './km'; import kmPages from './km-pages'
const MESSAGES = { en, km: { ...kmPages, ...km } }
const KEY = 'app-lang'
const read = () => { try { const v = localStorage.getItem(KEY); return v === 'en' || v === 'km' ? v : null } catch { return null } }
const chosen = ref(read()); const fallback = ref('en')
export const lang = computed(() => chosen.value ?? fallback.value)
export function setLang(v) { chosen.value = v; try { localStorage.setItem(KEY, v) } catch {} }
export function setDefaultLang(v) { fallback.value = v }
export function t(key, params = {}) {
  if (!key) return ''
  const text = MESSAGES[lang.value][key] ?? MESSAGES.en[key] ?? key
  return text.replace(/\{(\w+)\}/g, (_, n) => params[n] ?? `{${n}}`)
}
```
- Named keys (`'menu.rooms'`) for shared UI; plain English text as the key (`t('Add Room')`) on admin pages, with the
  translation in `km-pages.js`. A missing key falls back to English, then to the key itself.
- `main.js`: `app.config.globalProperties.$t = t`; set the default language from the role after login.
- Keep `document.documentElement.lang` in sync (`watchEffect`) so CSS can target `html[lang='km']`.
- Khmer fonts: `'Kantumruy Pro', 'Khmer OS Siemreap', 'Noto Sans Khmer'` as fallbacks after the Latin font;
  no `letter-spacing` on Khmer text; printable documents use `Khmer OS Muol Light` for titles.
- Format money and months with helpers (`formatRiel`, `monthName(period)`), never inline.

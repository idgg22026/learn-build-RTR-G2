# rtr-fullstack-builder (Claude Code plugin)

| Skill | Use |
|---|---|
| `new-project` | `/rtr-fullstack-builder:new-project <folder> [description]` |
| `add-module` | `/rtr-fullstack-builder:add-module <Thing> [plural] [field:type …]` |
| `check-rules` | `/rtr-fullstack-builder:check-rules [module or path]` |
| `fullstack-laravel-vue-builder` | loads automatically for Laravel + Vue app work; holds the rules, references, templates and scripts |

Install and usage: see the main [README](../README.md#add-the-skill-to-claude).
